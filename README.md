# Marco Digital

Portfolio personale dedicato a prodotti digitali, applicazioni gestionali e automazioni progettate per risolvere problemi reali.

**Sito online:** [marchettoh.github.io](https://marchettoh.github.io/)

## Il progetto

Il sito presenta una selezione dei progetti sviluppati, il metodo di lavoro e tre formule di collaborazione mensile rivolte ad aziende e professionisti.

È stato progettato come sito statico, veloce e senza dipendenze, così da poter essere pubblicato direttamente tramite GitHub Pages.

## Progetti in evidenza

- **Gestora** — piattaforma gestionale per attività food
- **RhioGo** — suite mobile e web per consegne e fattorini
- **FileFlip** — strumento per la conversione dei file
- **Cashline** — dashboard per la gestione delle finanze quotidiane

Il portfolio include inoltre Rhio Hub, RhioOrari, RhioOrdini, RhioMagazzino, RhioFormazione, Rhio Sito, La Gastronomia, La Gastronomia Ordini, Cremix e Cioccolato di casa.

## Caratteristiche

- Design responsive per desktop, tablet e smartphone
- Collage visuale dei progetti
- Animazioni progressive e supporto a `prefers-reduced-motion`
- Navigazione accessibile da tastiera
- Sezione servizi con prezzi indicativi
- Contatto diretto tramite email
- Favicon vettoriale personalizzata
- Compatibilità nativa con GitHub Pages

## Tecnologie

- HTML5
- CSS3
- JavaScript
- GitHub Pages

Non sono richiesti framework, package manager o processi di compilazione.

## Avvio in locale

È possibile aprire direttamente `index.html` nel browser oppure avviare un server statico nella cartella del progetto.

Con Python:

```bash
python -m http.server 8000
```

Il sito sarà disponibile all'indirizzo `http://localhost:8000`.
